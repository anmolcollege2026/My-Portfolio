# Anmol Verma —  Personal Portfolio

> **"Curious Mind. Exploring Technology. Building Ideas."**  
> An experimental, cinematic, and interactive digital portfolio engineered for **Anmol Verma**, 1st-Year AI & Data Science student at the **University School of Automation and Robotics (USAR)**.

---

## ⚡ Key Highlights & Interactive Features

- **Cinematic Genesis Entrance**: Kinetic letter-by-letter fragment reassembly, 3D mouse parallax, dynamic gravitational particle matrix, and an interactive "DISTORT REALITY" spatial warp trigger.
- **Narrative Stream (About Section)**: Kinetic storytelling through animated chapters (**CURIOUS**, **EXPLORE**, **BUILD**, **LEARN**) splitting into a holographic USAR student telemetry record.
- **Interactive Skills Compiler Matrix**: Floating physics-based skill nodes (`C`, `C++`, `Python`, `HTML`, `CSS`, `JavaScript`). Selecting any skill triggers a **Live Compiler Terminal** running real algorithmic code snippets and execution logs!
- **Multi-Dimensional Project Showcase**: Interactive project cards with telemetry benchmarks, category filters, and full-screen inspection modals with GitHub and live demo launch links.
- **Surprise CyberShell Console**: Press `~` or click `CONSOLE` in the top HUD to launch an interactive retro-futuristic terminal supporting commands: `help`, `about`, `skills`, `projects`, `contact`, `warp`, `matrix`, `clear`.
- **In-Browser Tactile Sound Synthesizer**: Pure Web Audio API spatial synthesizer creating high-tech clicks, warps, and chimes on interaction with a global mute toggle.
- **Butter-Smooth Inertia Scrolling**: Powered by **Lenis** with hardware-accelerated transforms and reduced-motion accessibility support.
- **Tactical Floating HUD**: Live coordinate telemetry, dynamic scroll progress indicator, and rapid warp anchors.
- **Single-Source Configuration**: All personal info, projects, skills, and links are managed in `src/portfolioData.ts`.

## 🚀 Getting Started Locally

### 1. Prerequisites
Ensure you have **Node.js** (v18 or higher) installed on your system.

### 2. Installation
Open your terminal in the project directory and run:

```bash
npm install
```

### 3. Running the Development Server
Start the local development server:

```bash
npm run dev
```

Open your browser and navigate to **`http://localhost:5173`** (or the port displayed in your terminal).

### 4. Creating a Production Build
To generate an optimized production bundle:

```bash
npm run build
```

The production output will be generated in the `dist/` directory.

### 5. Previewing the Production Build
```bash
npm run preview
```
